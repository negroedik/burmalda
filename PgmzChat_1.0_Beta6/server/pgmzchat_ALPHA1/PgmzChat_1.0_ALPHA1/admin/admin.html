Сначала подключись к серверу, чтобы загрузить список устройств.

Панель предназначена для временного управления кодами устройств. Блокировка действует на зарегистрированный код устройства; это не абсолютный hardware ID — переустановка, очистка данных или изменённый клиент могут дать новый код. Панель не читает сообщения, фотографии, пароли и историю чатов: сервер их не хранит.
