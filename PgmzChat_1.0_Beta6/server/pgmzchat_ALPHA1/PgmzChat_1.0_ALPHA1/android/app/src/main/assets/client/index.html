Что делает сервер

Сервер хранит только ID аккаунта, username, соль и хеш пароля. Поиск сообщений, история, комнаты, контакты, медиа, реакции и закрепления на сервер не отправляются: они хранятся у участников и передаются через P2P. Для поиска пользователя сервер возвращает только публичные ID и username.

Для регистрации и временной WebRTC-сигнализации сервер должен быть доступен. Для публичного использования настрой HTTPS. Этот prerelease — экспериментальная mesh-сеть, а не проверенная BitTorrent-сеть; фоновая доставка пока не гарантирована.

ЛОКАЛЬНОЕ ХРАНИЛИЩЕ

Менеджер хранения

Статистика обновляется кнопкой «Посчитать».

История между телефонами (P2P · бета)

Оба разрешения всегда включены; передача истории в этой бета-версии работает в личных чатах.

Очистка удаляет копии только на этом телефоне. Сообщения и вложения не хранятся на сервере. P2P требует онлайн-участников; в сетях, где прямые соединения запрещены, обмен может не работать без TURN-релея.
