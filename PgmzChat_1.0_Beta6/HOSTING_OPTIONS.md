# 10 вариантов временного хостинга для PgmzChat

**Для этой конкретной сборки первым пробуй Render.** В архиве уже настроены `render.yaml`, Node.js server, HTTPS, бесплатная PostgreSQL и секрет администратора. Полностью бесплатный тариф не означает постоянную работу или гарантированное хранение данных.

| № | Хостинг | Что с бесплатным режимом | Совместимость с этим проектом | Ссылка |
|---:|---|---|---|---|
| 1 | **Render** — лучший старт | Web Service free; бесплатная PostgreSQL на 30 дней; сервис засыпает после 15 минут простоя | **Подготовлено в архиве.** Blueprint создаёт приложение + базу и задаёт секрет | https://render.com/docs/free |
| 2 | **Northflank** | Бесплатный Sandbox даёт до 2 сервисов и 1 базу; сервисы не засыпают, но нужен способ подтверждения аккаунта/платёжный метод | Подходит Node.js + PostgreSQL; потребуются подключить GitHub и переменные | https://northflank.com/pricing |

### Не перепутай простой статический сайт с полноценным сервером

Netlify тоже удобен для статического сайта, но текущий PgmzChat нуждается в API регистрации/входа, временном присутствии и WebRTC-сигнализации. Поэтому публикация одних HTML/CSS/JS-файлов не заменит развёртывание Node.js-сервера и БД.

### Почему выбран Render

Из перечисленных вариантов именно для него этот архив содержит готовое описание ресурсов. Нужно один раз разместить проект в GitHub и создать Blueprint. Если тебе важнее, чтобы приложение не засыпало, рассмотри Northflank, но его регистрация обычно требует указать платёжный метод. Если важнее совсем без настройки сервера, Render проще — при этом помни об истечении PostgreSQL через 30 дней.
